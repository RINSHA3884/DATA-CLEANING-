This assignment focuses on data cleaning, data formatting, and basic data analysis using Microsoft Excel.

The dataset contains product-related information such as Product ID, Product Name, Brand Name, Category, Price, and Manufacturing Date.

The main objectives of this assignment are to:

* Identify and handle missing values.
* Identify and correct inconsistent text formats and spelling errors.
* Remove duplicate records.
* Split and combine data from different columns.
* Format dates and prices appropriately.
* Apply conditional formatting to improve data visualization.
* Create custom conditional formatting rules based on specific categories.
* Use Excel formulas and built-in tools to clean and organize the dataset.

Through these tasks, the assignment demonstrates practical skills in Excel data cleaning, formatting, transformation, and visualization.# DATA-CLEANING-
